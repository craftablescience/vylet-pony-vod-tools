# Vylet Pony VOD Tools

A collection of tools for archiving Vylet Pony's streams.

- `subtitle_dl.py` — Download YouTube's autogenerated subtitles and live chat for all available VODs.
- `subtitle_search.py` — Search downloaded subtitles for a keyword or phrase.
- `thumbnail_generator.py` — Generates thumbnails for reuploaded VODs.
